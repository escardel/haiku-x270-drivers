The TrackPoint/touchpad installer now includes the tested native touchpad gesture add-on:

- One-finger tap-to-click and three-finger tap middle-click.
- Two-finger scrolling stays in scroll mode through uneven finger lift-off, avoiding pointer jumps.
- Scheduled button release prevents multi-finger taps from remaining held.

The existing working PS/2 module is unchanged. Source, the gesture patch, a native build/test script, licenses and checksums are included. The webcam, microphone/audio and Bluetooth payloads are unchanged from 2026.10.22.1.

These installers target **Haiku hrev59866+92 x86_64 on the ThinkPad X270**. Extract the desired ZIP, run `bash install.sh --verify`, then `bash install.sh --install`, and reboot. To upgrade an existing component, first run `--uninstall` from its previous extracted installer. Keep the previous installer and receipt backups until verified. Tapping follows Input preferences: zero sensitivity disables it; positive values enable light taps.

Validation on the X270: all four ZIPs passed checksums; the touchpad source rebuilt and passed 22 gesture checks; the packaged pointing-device binaries match the working installation. The user confirmed movement, taps, middle-click and stable scrolling. Isolated installer tests passed install/uninstall, preservation of an existing override, changed-file refusal and failure rollback.
