# X270 keyboard shortcuts 2026.11.07.1

Separate input-server filter utility for Haiku hrev59866+92 x86_64.

## Native package

Open `x270_keyboard_shortcuts-2026.11.07.1-1-x86_64.hpkg` for graphical
installation. The native package installs the input-server filter directly;
it contains no boot scripts or post-install commands. `Keyboard-SHA256SUMS`
covers it and `x270-keyboard-2026.11.07.1-native-x86_64.zip`, which includes
source, tests and rebuild instructions. The exact Haiku revision dependency
matches the original script installer's gate.

The package was installed on the X270 and its filter loaded successfully
from `/boot/system/add-ons/input_server/filters/fn_shortcuts`. The previous
manual filter was backed up under `/boot/home/AI/fn-shortcuts/` and removed
from the watched directory to avoid overriding the packaged copy. A first-time
home install may require rebooting if the add-on directory was absent at
input_server startup. See `keyboard/README.md` for migration and uninstall.

## Shortcuts and legacy ZIP

F1 mute, F2/F3 volume, F5/F6 brightness, F7 borderless fullscreen,
F9 preferences, F11 Terminal, F12 Firefox executable.
F4/F8/F10 are disabled. Alt+, snaps left; Alt+. snaps right, with the
window border inside its screen half. Alt+/ maximizes with the border intact.
Either Alt key works.
Hold either physical Alt before pressing a function key to pass its original
key events and modifiers through to applications. Volume/mute/brightness
show a native popup for 1.5 seconds, replacing the previous level popup.

Extract the ZIP and run `bash install.sh --verify`, then
`bash install.sh --install`. Run `bash install.sh --uninstall` to restore
a previously installed filter. Exit F7 fullscreen before replacing/removing.
No reboot is normally needed. The supplied binary rejects other revisions;
source is included for rebuilding. This uses private window APIs for F7.

Validation: clean compile, all key routing/repeat tests passed, fullscreen entry/restore and both half-screen snap directions passed live tests,
including snapping out of fullscreen, and popup mixer
readback and notification sends succeeded. The previous build was loaded
live on the X270; this distribution build uses the user's log directory and adds
the window management shortcuts and keeps F12 assigned to Firefox. Brightness requires driver support; notifications
must be enabled. Application toolbars remain visible in F7 fullscreen.

Rebuild: run `make` in `keyboard`, copy `fn_shortcuts` to
`artifacts/keyboard-haiku-x86_64-hrev59866+92/`, then run
`python3 keyboard/build_bundle.py` from the repository checkout.
