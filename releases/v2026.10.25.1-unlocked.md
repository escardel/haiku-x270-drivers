# Experimental version-unlocked X270 drivers ? UNTESTED

**EXPERIMENTAL AND UNTESTED. We have no way to test these packages. They have not been installed or runtime-tested on Haiku. They may cause crashes, loss of input/audio, or a system that cannot boot normally. Save work and keep a known-good boot/recovery option before installing.**

Four separate ZIP installers are attached: TrackPoint/touchpad, webcam, microphone/audio, and Bluetooth, plus SHA256SUMS. These are newly packaged copies of the existing hrev59866+92 x86_64 binaries, not newly compiled drivers.

## Version-unlocked installation

The installers **automatically force past the Haiku version/revision check on any Haiku x86_64 revision**, including older and newer versions. No extra force flag is required. This removes the installer restriction; it cannot make the binaries ABI-compatible with every Haiku version. **32-bit Haiku is unsupported.** Checksums, backups, existing-installation receipts and webcam dependency checks remain enforced.

Extract only the component you need with Expander. Open Terminal in its extracted directory:

```sh
bash install.sh --verify
bash install.sh --install
```

Reboot afterward. `--verify` checks package integrity only, not driver compatibility. Webcam requires `pkgman install libjpeg_turbo`. Microphone installation restarts media services and changes audio configuration. Bluetooth adds a marked UserBootscript startup command. For an existing X270 component installation, uninstall it using its previous extracted installer before installing this release; do not delete its receipts to bypass this requirement.

## Remove / restore previous drivers

Keep each extracted installer and its backups. From that same component directory:

```sh
bash install.sh --uninstall
```

Repeat for each installed component, then reboot. Uninstall has no Haiku revision restriction. It restores previous custom overrides (or removes new overrides to expose packaged originals), restores saved microphone audio settings, and removes the managed Bluetooth startup entry. Packaged system originals are not overwritten. Receipts and backups are in `/boot/home/config/settings/x270-drivers/COMPONENT`, where COMPONENT is `trackpoint-touchpad`, `webcam`, `microphone`, or `bluetooth`. Completed receipts are archived with a timestamp.

If uninstall reports changed binaries, stop and review the changed paths; it refuses to overwrite later changes. Keep the receipt and backups. Restore the installed files from the matching ZIP before retrying only if you intend to discard those later changes, or recover manually using the receipt as described below.

### If Haiku cannot boot normally

Use Haiku's boot menu to disable user add-ons and try booting. If that is insufficient (for example, a system library override prevents startup), boot a known-good Haiku installation or USB recovery medium and mount the affected volume. The following paths refer to the affected installation; use its mounted volume prefix when working from recovery media.

Read `/boot/home/config/settings/x270-drivers/COMPONENT/backups.list`. Each line is `destination|existed|backup-number`. If `existed` is `1`, restore `backups/backup-number` from that receipt directory to the exact destination, preserving symlinks and permissions. If `existed` is `0`, remove only that destination override. Do not delete packaged files or the backups. The extracted `files.list` also lists this component's installed destinations.

Typical overrides include:

- TrackPoint/touchpad: `/boot/home/config/non-packaged/add-ons/kernel/bus_managers/ps2` and `/boot/home/config/non-packaged/add-ons/input_server/devices/mouse`.
- Webcam: `/boot/home/config/non-packaged/add-ons/media/aukey_webcam_v4.media_addon`.
- Microphone/audio: `/boot/home/config/non-packaged/add-ons/kernel/drivers/bin/hda`, its `dev/audio/hmulti/hda` link, the media mixer add-on, and `/boot/system/non-packaged/lib/libmedia.so`. Restore the saved Media settings using the same receipt.
- Bluetooth: `/boot/system/non-packaged/lib/libbluetooth.so` and files under `/boot/home/config/non-packaged/data/x270-drivers/bluetooth`. Remove the `# X270 managed Bluetooth startup` marker and its associated `start-bluetooth.sh` command from `/boot/home/config/settings/boot/UserBootscript` to disable automatic startup. Reboot to stop the custom server.

Reboot after recovery. Retain receipts for diagnosis; manual recovery does not mark an installation as normally uninstalled.
